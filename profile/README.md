# Build Internet

### Open-source tools for people and coding agents.

[Website](https://buildinternet.com) · [Releases](https://releases.sh) · [Uploads](https://uploads.sh) · [Buildnotes](https://buildnotes.releases.sh)

Releases, Uploads, and Buildnotes are the main projects.

### Projects

| Project | What it is |
| --- | --- |
| [Releases](https://releases.sh) | An index of product release notes and changelogs. People and agents read the same index. [Source](https://github.com/buildinternet/releases) |
| [Uploads](https://uploads.sh) | A place for the screenshots, recordings, and other files a coding agent puts on a pull request. [Source](https://github.com/buildinternet/uploads) |
| [Buildnotes](https://buildnotes.releases.sh) | Turns the history of a feature into a post about how it was built and why. [Source](https://github.com/buildinternet/buildnotes) |

More projects are in the repositories on this page.
